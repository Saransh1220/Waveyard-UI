Icons & identity

Use the installed Font Awesome Solid set for common actions. Match each symbol to one action across cards, rows, navigation, and the player.

Icon sizing

Proposed sizes. Use 16px in text controls, 20px for standalone actions, and 24px for prominent playback. Give touch actions a 44px target. Name icon-only actions and show keyboard focus. Keep purpose-built brand, waveform, and basket artwork where it serves the interface.

Audit coverage and limits

Before adding a component

  • Start with the closest shared component or screen pattern.
  • Check theme colors, keyboard focus, and icon labels.
  • Review loading, empty, error, disabled, selected, and success states that apply.
  • Review narrow and wide layouts with relevant navigation and overlays in place.
  • Update this guide when an agreed pattern or token changes.
